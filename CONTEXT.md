# Django Users Berlin

The vocabulary used for Django Users Berlin's event pages.

## Language

**djub**:
Django Users Berlin, the community whose events are presented on this site.

**Event page**:
A page with a short description of a djub event, intended primarily for display on a screen. It may include one QR code.

**QR destination**:
The link attendees open by scanning an event page's optional QR code.

**Page alias**:
A short alternative address for an existing page, leading visitors to that page's primary address.
